# Digital Portfolio Capstone Project

Welcome to my Capstone Project repository for the **GitHub Essentials for Non-Programmers** course!

## 📌 Project Overview
This repository serves as a personal digital portfolio designed to showcase my background, skills, and course projects using version control and documentation practices.

## 📁 Repository Structure
- `index.html` — The main landing page for GitHub Pages.
- `assets/` — Folder containing project media and images.
- `docs/` — Folder containing additional project documentation.
- `README.md` — Project overview and navigation instructions.

## 🛠️ GitHub Features Used
- **Version Control & Commits:** Documenting changes with descriptive commit messages.
- **Markdown:** Formatting project notes and documentation cleanly.
- **GitHub Pages:** Hosting and rendering a live web page directly from the repository.
